One run, step by step

  1. The Growth Lead pastes the week's domains and clicks Run. Nothing runs before that.
  2. Code cleans every domain, removes duplicates, and quarantines any site whose robots.txt says no.
  3. Signal fetches the company's homepage, falling back to a reader service if the page is thin.
  4. The run loads the current weights and switches, last runs' rejections, and cached Hunter and AI answers.
  5. Gemini reads the page into four facts. Each fact needs a word-for-word quote, or it stays "not stated".
  6. If a fact is still missing and fewer than 4 extra pages have been read, the loop goes again. Code makes that call.
  7. Gemini suggests the next page, such as /security, /pricing or /careers. Every choice is logged with its reason.
  8. If no page states the company's size, Hunter's company data fills it, labelled as Hunter's.
  9. The rules engine checks fit, adds up the timing signals and gives Send, Hold or Drop with a rule ID. A SOC 2 claim on any page counts as already certified.
  10. For companies that fit, Hunter finds named people and code picks one by role for the company's size.
  11. Gemini names two pain points and writes the email to that person by first name, opening on a fact from their site.
  12. Code checks every quote against the fetched pages. A draft that fails cannot be sent.
  13. With auto_send on, each checked Send goes straight to the Growth Lead's own inbox. The recipient cannot be changed from the app.
  14. The Growth Lead reads the reasons, moves weights to re-rank without new fetches, and rejects with a reason what should not come back.

What changed from the original map

  • Emails open "Hi <first name>," and end with a Sprinto sign-off, so each one is addressed to a real person by name. Draft with no greeting
  • auto_send now sends every checked Send as soon as its draft is written, as the brief asks. Every send needed a click; the auto_send switch did nothing
  • A SOC 2 or ISO 27001 claim on any page read marks the company as already certified, so it gets the migration pitch. Certification set by the first page that mentioned security
  • When the site never states a headcount, Hunter's company data supplies it, labelled as Hunter's. Size missing at the page cap held almost every company
  • Email goes through Resend to the Growth Lead's own inbox. Gmail stays first in line if its keys are added. Gmail API only
Stack: Next.js on Vercel · TypeScript rules engine · Neon Postgres · Gemini gemini-3.8-flash · Hunter.io Domain Search and Company Enrichment · Resend (Gmail API supported) · r.jina.ai reader fallback
Needed before real outreach: a paid Hunter plan (a new company can use 2 of the 50 free credits), a verified sending domain on Resend or Gmail keys, and a decision to email prospects directly. Today every email goes only to the Growth Lead's own inbox, as the brief requires.
